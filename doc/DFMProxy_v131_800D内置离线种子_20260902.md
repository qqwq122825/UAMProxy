# DFMProxy v1.131.0：800D 内置离线种子

## 结论

- 中央9类继续使用程序内置的权威模板，不从玩家录制池取值。
- 单独开启800D后，取值优先级为：Live精确slot → 录制供体（同设备优先）→ 内置种子。
- 内置回退不依赖当前账号、IDFV或玩家录制，可直接按离线轨迹生成。
- 旧版全额重建兼容入口保持既有门控；新行为只挂在v3的800D独立开关上。

## 历史验证

对30天日志中的800D进行结构扫描：

- 共328条有效记录，分布于68个文件；
- 64字节长度一致；
- slot序列为`60, 660, 1260, ...`，周期固定600；
- `+0x20`计数为`1, 21, 41, ...`，公式为`1 + cycle × 20`；
- 上述轨迹零偏差；
- `+0x24=0x20250513`、`+0x28=1`稳定，`+0x2C/+0x30`按内置基准种子保留。

## 实现

内置种子提供slot 60和660两个权威锚点，复用既有、已经回归验证的周期外推器生成后续slot。运行日志写出：

- `builtin_800d_fallback`
- `builtin_800d_seed_revision`
- `800d_source`

其中`800d_source`用于区分`selected_recording`、`same_device_donor`、`cross_device_donor`和`builtin`。

## 回归

`tests.test_v128_replenish`共70项通过，新增覆盖：空录制池、空设备上下文、600-slot连续轨迹、Live同slot优先、800D关闭保持静默，以及完整重放管线注入。
