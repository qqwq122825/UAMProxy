# v128 AI机器日志

默认运行目录：

`C:\PyProxyApp\AI日志\run_YYYYMMDD_HHMMSS_microseconds`

每次代理启动建立一个运行目录。日志以`manifest.json`为入口，其他文件均为UTF-8、LF换行、每行一个JSON对象。

## 核心文件

- `replay_events.jsonl`：一次重放决策一行，记录模型版本、会话时间、四类offset前后值及所引用的group ID。
- `replay_groups.jsonl`：每个逻辑组一行；`phase=input/template/shadow/output`，输出组再以`source=native/v128_central9/v128_player_same_device`区分。
- `replay_leaves.jsonl`：每个Type9叶一行，保留数值ID、Hex镜像、序号、slot、长度、SHA-256及原始Hex。
- `record_frames.jsonl`：录制端完整物理帧。
- `record_reports.jsonl`：录制端已解密Type9报告。
- `record_leaves.jsonl`：录制端逐叶规范化记录。
- `record_sessions.jsonl`：录制会话开始、更新和结束。
- `stream_frames.jsonl`：01通道的`recv/sent/sent_live`完整帧，包含42B会话加入帧。
- `downlink_events.jsonl`：录制/重放下行帧及处置结果。
- `template_selection_events.jsonl`：连接级个人池/官方池选择结果。

机器字段以整数为主，`*_hex`只是对照镜像；缺失值使用`null`，时间同时保留`time_unix_ms`和ISO-8601。

## 快速校验

```bash
python tools/analyze_ai_logs.py "C:\PyProxyApp\AI日志\run_..."
```

脚本流式读取manifest、event、group和leaf，重新校验报告/叶/物理帧/包组序号连续性，并输出消息ID计数与`pass/error_count`。
