# DFMProxy v1.123.3 双设备模式与tfp_called专项语义槽

## 问题来源

123.1样本的正常录制来自`iPhone18,2 / iOS 26.5.1`，重放Live来自
`iPad13,4 / iOS 14.6`。只对部分消息使用手机模板、其余消息保留iPad，会同时出现
手机代码指纹和iPad根设备字段。多人共用时也可能从不同录制会话分别选中模板。

因此123.2把设备策略提升到连接级，提供两个互斥模式；一个连接确定模式和录制会话后
全程保持不变。

## 模式一：继承重放设备

配置值：

```ini
type9_device_mode = inherit_live
```

处理方式：

- 根设备身份使用当前Live；
- `0x1007/0x1008/0x1009/0x100C`由基座默认保留Live，不占用热规则表；
- `0x100B/0x100F/0x8027/0x8029`只有型号、系统主版本及已知应用标识兼容时才使用模板；
- 缺少设备上下文或没有同设备模板时使用`DEVICE_CONTEXT_PASS_LIVE`；
- `0x0207/0x2001/0x2000/0x1105/0x9000`等专项规则继续执行；
- `tfp_called`命中正常语义槽后，把模板`model/ver`写回Live设备值。

此模式适用于录制池中已经有当前重放设备的干净样本。

## 模式二：替换录制设备

配置值：

```ini
type9_device_mode = replace_recorded
```

处理方式：

1. 新连接按“玩家个人池优先、已发布官方池其次”的顺序选择录制会话；
2. 优先选择能提取设备型号的会话，并把`template_session_id`锁定到连接状态；
3. 后续全部模板候选只来自该会话，避免跨设备、跨批次拼接；
4. `0x1007/0x1008/0x1009/0x100B/0x100C/0x100F/0x8027/0x8029`
   统一使用锁定会话的最近长度模板；
5. 其他模板规则也只在锁定会话中选取；
6. 账号、物理连接头、recordSequence、报告序号、运行计数及`inc_id/obf_id`仍继承Live。

这里四条代码指纹消息同样由基座的设备模式分支处理，因此拦截管理只显示真正执行
专项改写的九条热规则；删除旧版四条`pass_live`行不改变两种设备模式的输出。

连接内统一的录制设备字段包括：

```text
model
iDevHwModel
ver / iDevSysVer
iDevSysName
iDevIDFV
iDevRes
iAppVersion
iAppMachUUID
```

即使某条未知叶子回退到Live，只要正文携带上述字段，也会执行
`RECORDED_DEVICE_PROFILE_REWRITE`，避免残留重放设备身份。设备字段变长时会重建叶子、
父容器、Type9明文CRC、密文、01物理分片及外层CRC。

## `tfp_called`专项语义槽

已确认两种命中形式：

```ini
recordCode = 0x0112233B
text       = tfp_called
```

以及123.2实机数据新增确认：

```ini
recordCode = 0x01122329
text       = tfp_called
```

两者都使用无`tfp_called`的正常`0x01122329`叶子。候选选择先匹配相同
`inc_id/obf_id`；干净录制没有当前递增槽位时，回退到长度及序号最近的干净
`0x01122329`，随后把Live的`inc_id/obf_id`写回。继承模式同时写回Live的
`model/ver`，替换模式使用连接锁定的录制设备画像。两级模板都缺失时，只有完整
匹配实机确认的`0000000001000000000B + tfp_called`编码签名才删除20字节字段；
签名不符时保留Live并记录结构异常。

处理流程：

1. 从Live读取`inc_id/obf_id`；
2. 在当前可用录制会话中优先查找相同槽位的正常`0x01122329`，未命中则选择最近干净槽；
3. 使用正常recordCode及正文，保留Live recordSequence和`inc_id/obf_id`；
4. 继承模式写回Live设备字段；替换模式保留并统一录制设备字段；
5. 无模板时按确认签名删除完整`tfp_called`编码字段；
6. 变长重建全部长度和CRC。

日志级别为`CROSS_RECORD_SLOT_REPLACE`。

## 界面与3366

“连接与重放”页工具栏提供“设备模式”下拉框：

- `继承：使用重放设备`
- `替换：使用录制设备`

模式在连接首次处理Type9报告时固定，切换后由新连接生效。原顶部“阻断3366”实验按钮
已移除；3366继续按专版策略字节级透传。
